# Parked for after launch

These pages are kept (copy, layout and data intact) but are **not routed**: Next.js ignores folders that start with an underscore.

- `grounded/` — the GROUNDED streams page
- `next-steps/` — the "Find where you are" page

To bring one back, move its folder up into `app/`, re-add it to `lib/nav.ts` (`NAV_MORE`) and `app/sitemap.ts`, and check the copy first.
